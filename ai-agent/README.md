## 🤖 กฎสำหรับ AI Agent (Workflow Rules)
1. **เมื่อมีการวางแผนใหม่:** ให้สร้างไฟล์ลงในโฟลเดอร์ `todo/`
2. **เมื่อทำงานเสร็จสิ้น:** ให้ย้ายไฟล์จาก `todo/` ไปยังโฟลเดอร์ `history/`
3. **อัปเดต README เสมอ:** ทุกครั้งที่สร้างแผนงานใหม่ หรือย้ายไฟล์ที่ทำเสร็จแล้วไปยัง `history/` **จะต้องกลับมาอัปเดตไฟล์ `README.md` นี้ทุกครั้ง** เพื่อให้สารบัญตรงกับสถานะปัจจุบัน
