# แผนการปรับปรุงสำหรับ Android (TODO)

เนื่องจากเราตัดสินใจใช้การ Import ไฟล์ `.fit` แทนการรับข้อมูลผ่าน COROS API (ที่ต้องขอสิทธิ์ในนามบริษัท) ขั้นตอนต่อไปคือการปรับแต่งแอปพลิเคชันให้พร้อมและเหมาะสมสำหรับการใช้งานบนมือถือ Android ครับ

## 1. การจัดการ Database (SQLite) บน Android
**ปัญหาที่อาจพบ:** บนคอมพิวเตอร์ (Mac/Windows) Path ของไฟล์ SQLite มักจะโปร่งใสและเข้าถึงง่ายดาย แต่บน Android ไฟล์จะต้องถูกสร้างและจัดการใน Application Sandbox (Internal Storage) โดยใช้ Path ที่ถูกต้องผ่าน `tauri-plugin-sql`
- [x] **ตรวจสอบโค้ดการเชื่อมต่อฐานข้อมูล:** ให้แน่ใจว่าใช้คำสั่ง `appDataDir()` หรือช่องทางที่ Tauri จัดเตรียมไว้ เพื่อให้แอปบน Android สามารถสร้างและเขียนไฟล์ `sqlite.db` ได้โดยไม่มีปัญหา Permission
- [ ] **ทดสอบบันทึกข้อมูล:** ทดสอบสร้าง Profile หรือนำเข้าไฟล์ `.fit` บน Android Emulator เพื่อยืนยันว่าข้อมูลถูกบันทึกลง SQLite จริงๆ และไม่หายไปเมื่อปิดแอป

## 2. ปรับปรุง Frontend UI/UX สำหรับมือถือ (Mobile Responsive)
**เป้าหมาย:** ตอนนี้แอปถูกออกแบบมาสำหรับ Desktop (Mac/Windows) เป็นหลัก หน้าจอต่างๆ อาจจะล้นหรือปุ่มเล็กเกินไปเมื่อแสดงผลบนจอมือถือ
- [x] **Navigation (แถบเมนู):** 
  - ซ่อน Sidebar ด้านซ้ายแล้วเปลี่ยนมาใช้ **Bottom Navigation Bar (เมนูด้านล่าง)** หรือ **Hamburger Menu** ที่รองรับการสัมผัส (Touch-friendly) เพื่อความสะดวกบนมือถือ
- [x] **รูปแบบการแสดงผล (Layouts & Charts):**
  - กราฟ Recharts ต่างๆ (หน้า Body Metrics, หน้า HR Zones) อาจจะดูอึดอัดบนจอแคบ ต้องปรับ `width` และ `margin` ให้เหมาะสม
  - แสดงแบบการ์ดข้อมูล (Cards) ให้เรียงเป็นแนวตั้ง (Stack) แบบ 1 คอลัมน์ บนหน้าจอมือถือ
- [x] **ขนาดปุ่ม (Touch Targets):** 
  - ขยายขนาดปุ่มกดต่าๆ (เช่น ปุ่ม Import .fit, ปุ่มตั้งค่า) ให้มีความสูงตามมาตรฐานมือถือ (ขั้นต่ำ 44px - 48px) เพื่อให้แตะง่าย

## 3. การจัดการไฟล์และการทำงานของ Native
- [ ] **File Picker:** 
  - ตรวจสอบว่า `tauri-plugin-dialog` ที่ใช้เปิดเลือกไฟล์ `.fit` จากโทรศัพท์ Android ทำงานได้ถูกต้องหรือไม่ (บางครั้ง Android ต้องการ Permission ในการเข้าถึงไฟล์)
- [ ] **Status Bar & Safe Area:**
  - เพิ่มขอบเขต Safe Area ด้านบน เพื่อป้องกันเนื้อหาแอปไปซ้อนทับกับ Status line (นาฬิกา, แบตเตอรี่) ของ Android
